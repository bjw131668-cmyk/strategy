# 제갈량 상소문 (上疏文)

매일 오전 7시, 그리고 컴퓨터를 켜고 로그인할 때마다 제갈량 말투의 조언 창을 띄웁니다.

폰에서 보기: https://claude.ai/artifact/THUw9yUB8eusCnidYQEfoh (본인 계정으로 로그인해야 열립니다)

- **제1표**: 클로드 코드를 처음 쓰는 분을 위한 사용법 (약 2,000자)
- **제2표**: 사업과 삶의 방향에 관한 조언 (약 3,000자)
- 맨 아래 **오늘의 계책**은 날마다 바뀝니다.

## 설치

이 `sangso` 폴더를 **내 컴퓨터의 계속 둘 위치**(예: `문서\sangso`)에 복사한 뒤:

| 운영체제 | 설치 | 제거 |
|---|---|---|
| Windows | `install-windows.bat` 더블클릭 | `uninstall-windows.bat` 더블클릭 |
| macOS | 터미널에서 `bash install-mac.sh` | `bash uninstall-mac.sh` |

- Windows: Edge가 있으면 주소창 없는 깔끔한 창으로 띄우고, 없으면 기본 브라우저로 엽니다. 관리자 권한은 필요 없습니다.
- 설치 후 폴더를 옮기면 다시 설치하세요.

## 폰에서 매일 아침 7시에 띄우기

**iPhone (단축어 앱)**
1. 단축어 앱 → 자동화 → 새로운 자동화 → **시간** → 오전 7:00, 매일 → **즉시 실행** 선택
2. 동작 추가: **URL 열기** → 위 폰용 주소 붙여넣기 → 완료

**Android (삼성 '모드 및 루틴')**
1. 설정 → 모드 및 루틴 → 루틴 → + → 조건: **시간** 오전 7:00, 매일
2. 실행할 동작: **앱 → 웹 페이지 열기**(또는 Chrome으로 URL 열기) → 위 주소

## 내용 바꾸기 (원본은 page.html)

`page.html`만 고친 뒤 `./build.sh`를 돌리면 PC용 `index.html`이 다시 만들어집니다.
폰용 페이지는 클로드 코드에게 "상소문 페이지 다시 올려 줘"라고 하면 같은 주소로 갱신됩니다.
클로드 코드에게 "내 사업은 ○○이다. 상소문 제2표를 이 상황에 맞게 다시 써 달라"고 부탁해도 됩니다.
