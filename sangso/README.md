# 제갈량 상소문 (上疏文)

매일 오전 7시, 그리고 컴퓨터를 켜고 로그인할 때마다 제갈량 말투의 조언 창을 띄웁니다.

- **제1표**: 클로드 코드를 처음 쓰는 분을 위한 사용법 (약 2,300자)
- **제2표**: 사업과 삶의 방향에 관한 조언 (약 3,300자)
- 맨 아래 **오늘의 계책**은 날마다 바뀝니다.

## 설치

이 `sangso` 폴더를 **내 컴퓨터의 계속 둘 위치**(예: `문서\sangso`)에 복사한 뒤:

| 운영체제 | 설치 | 제거 |
|---|---|---|
| Windows | `install-windows.bat` 더블클릭 | `uninstall-windows.bat` 더블클릭 |
| macOS | 터미널에서 `bash install-mac.sh` | `bash uninstall-mac.sh` |

- Windows: Edge가 있으면 주소창 없는 깔끔한 창으로 띄우고, 없으면 기본 브라우저로 엽니다. 관리자 권한은 필요 없습니다.
- 설치 후 폴더를 옮기면 다시 설치하세요.

## 내용 바꾸기

`index.html`을 메모장 등으로 열어 `第一表` / `第二表` 아래 `<p>...</p>` 문단을 고치면 됩니다.
클로드 코드에게 "내 사업은 ○○이다. 상소문 제2표를 이 상황에 맞게 다시 써 달라"고 부탁해도 됩니다.
